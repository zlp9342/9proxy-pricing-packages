## আগে নিজের কাজটা লিখে ফেলুন

প্রক্সি কেনার সবচেয়ে দামি ভুলটা হয় দাম দেখে সিদ্ধান্ত নেওয়া। আসলে সিদ্ধান্ত হয় কাজের ধরন দেখে।

বাংলাদেশের বায়ারদের বেশিরভাগ কাজ তিন ভাগে পড়ে:

- **অ্যাকাউন্ট ধরে রাখা** — ফেসবুক, ইনস্টাগ্রাম, হোয়াটসঅ্যাপ, টেলিগ্রাম, ফ্রিল্যান্স প্ল্যাটফর্মের প্রোফাইল। এখানে দরকার একই IP দিনের পর দিন ধরে রাখা। IP বদলে গেলে প্ল্যাটফর্মের কাছে সেটা সন্দেহের কারণ।
- **বাল্ক বা অটোমেটেড কাজ** — ডেটা স্ক্র্যাপিং, প্রাইস মনিটরিং, অ্যাড ভেরিফিকেশন, SERP চেক। এখানে একটা IP নয়, হাজার হাজার আলাদা অ্যাড্রেস দরকার, আর ডেটার পরিমাণই আসল খরচ।
- **দুইটাই** — কিছু অ্যাকাউন্ট স্থির রাখতে হবে, আবার ব্যাকগ্রাউন্ডে স্ক্র্যাপিং চলবে।

প্রথমটা করলে আপনার টাকা যাবে **IP-ভিত্তিক প্যাকেজে**, দ্বিতীয়টা করলে **GB-ভিত্তিক প্যাকেজে**। তৃতীয়টা হলে হিসাব করে বুঝতে হবে বান্ডল সস্তা পড়ছে কি না।

## সেটআপে কী কী লাগবে

GB-ভিত্তিক প্যাকেজ নিলে জীবন সহজ। ড্যাশবোর্ডে ঢুকুন, ইউজারনেম-পাসওয়ার্ড নিন বা আপনার সার্ভারের IP হোয়াইটলিস্টে যোগ করুন, তারপর স্ক্রিপ্ট বা ব্রাউজারে বসিয়ে দিন। রোটেটিং মোডে প্রতি রিকোয়েস্টে নতুন IP আসে, স্টিকি মোডে সেশন শেষ না হওয়া পর্যন্ত একই IP থাকে।

IP-ভিত্তিক প্যাকেজে একটা অতিরিক্ত ধাপ আছে — 9Proxy-এর ডেস্কটপ অ্যাপ নামাতে হবে। অ্যাপই আপনার লোকাল মেশিনে পোর্ট ফরওয়ার্ড করে IP-গুলোকে আপনার টুলের কাছে পৌঁছে দেয়। এর মানে আপনি VPS-এ বসে সরাসরি IP-ভিত্তিক প্যাকেজ ব্যবহার করতে পারবেন না। যারা Linode বা কনটাবোর মতো সার্ভার থেকে স্ক্রিপ্ট চালান, তাদের জন্য GB-ভিত্তিক প্যাকেজটাই স্বাভাবিক পছন্দ।

প্রোটোকল হিসেবে HTTP, HTTPS আর SOCKS5 — সবই পাওয়া যায়। ব্রাউজার এক্সটেনশন, Selenium, Puppeteer, যেকোনো স্ট্যান্ডার্ড টুলের সাথে কাজ করবে।

- **IP-ভিত্তিক প্যাকেজে ডেস্কটপ অ্যাপ বাধ্যতামূলক।** হেডলেস সার্ভার থেকে কাজ করলে ঝামেলা।

- **সোশ্যাল অ্যাকাউন্টে ডেটাসেন্টার IP ব্যবহার।** প্ল্যাটফর্মগুলো হোস্টিং রেঞ্জ চেনে, ফ্ল্যাগ উঠতে সময় লাগে না।

- **GB হিসাব না করা।** প্রতি রিকোয়েস্টে 300 KB করে ডেটা খরচ হলে 5 GB দুই-তিন দিনে শেষ। বাল্ক কাজে 50 GB বা 100 GB টায়ারে নামলে প্রতি GB-র দাম প্রায় অর্ধেক হয়ে যায়।

প্রশ্নটা হলো — আপনার কাজে IP-টা একই থাকা জরুরি, নাকি শুধু অনেকগুলো ঠিকানা দরকার? স্থির সেশনের দরকার হলে IP; ঘুরে ঘুরে অনেক রিকোয়েস্ট হলে GB।

### IP-গুলো কি মেয়াদ শেষে হারিয়ে যায়?
না। ব্যালেন্স-ভিত্তিক সিস্টেমে যে IP কিনেছেন সেগুলো এক্সপায়ার হয় না, যতক্ষণ না আপনি সেগুলো ব্যবহার করছেন।
